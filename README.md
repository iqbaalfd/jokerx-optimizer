# JokerX Optimizer

JokerX Optimizer adalah aplikasi desktop utilitas pengoptimal dan pemelihara sistem (*system optimizer & maintenance suite*) yang modern, ringan, dan berkinerja tinggi. Dibangun menggunakan antarmuka web modern dengan performa tingkat lanjut dan keamanan maksimal yang ditenagai oleh **Rust** serta **Tauri**.

## Fitur Utama

- **Antarmuka Profesional (Enterprise UI):** Tampilan bertema gelap (*dark-mode*) futuristik yang dilengkapi kotak konsol log aktivitas secara *real-time*.
- **Pembersihan Cache Mendalam:** Membersihkan file *temporary* sistem untuk mengoptimalkan ruang penyimpanan.
- **Reset & Perbaikan Jaringan:** Melakukan *flush DNS* secara instan untuk memulihkan koneksi jaringan komputer.
- **Arsitektur Ringan:** Menggunakan teknologi *native* di balik layar sehingga sangat hemat penggunaan RAM dibandingkan aplikasi berbasis Electron.
